Quests diárias

Quests diárias que valem a pena

São muitas, e dá para perder o dia inteiro nelas. Esta é a lista das que eu considero mais fáceis e com melhor retorno — e é uma opinião, não uma regra: quem joga diferente pode achar outras melhores.

Se você tem tempo de fazer todas, melhor ainda. Esta lista não é um teto, é o mínimo que vale a pena — pensada para quem tem uma hora, não para quem tem a tarde.

No seu personagem principal

Lobo Solitário. Dá duas entradas de cada instância. Só funciona em um personagem por IP, então não adianta repetir nas contas secundárias — escolha bem em qual fazer.

Vale pegar logo no começo, só para não esquecer. Não é que a ordem mude alguma coisa; é que esta é fácil de deixar para depois e perceber tarde demais que o dia acabou.

As três entradas

Pegue uma de cada instância. Dá para pegar as três rapidamente indo até a base da sua guilda, ou indo até a entrada de cada uma das dungeons.

Cinco quests do calendário

São elas que dão os itens de melhoria do personagem: runas, panaceia, moedas de prata e outros.

Hoje em dia dá para fazer as cinco em pouquíssimo tempo — menos de uma hora.

Se você está sem tempo

Procure um grupo de instância de diárias. Esses grupos fazem uma dungeon de cada tipo, uma vez — e só isso já cobre três das cinco quests do calendário.

O Caçador de Recompensas conta dobrado. Se você pegou essa, ela também é uma do calendário — e a conclusão dela é a conclusão de uma das três instâncias. Um ponto extra de graça.

Para a quinta, duas opções fáceis:

  • A quest do vigor, que é importante para subir o céu arcano.
  • Um Vale da Fênix, que é das mais rápidas que existem — e dá para fazer cinco por dia.

Por que as do calendário importam tanto

Elas são a fonte constante de panaceia e runas — os dois itens que todo mundo acaba precisando, seja para o conduíte ou para subir uma runa.

Um dia de diárias não parece muito. Trinta dias é a diferença entre ter e não ter.

Esta lista é pessoal, de quem joga — não é uma tabela do jogo nem a única forma de fazer. Se você faz diferente e funciona melhor, conte no Discord que eu acrescento.
